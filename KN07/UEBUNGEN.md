Nehmen Sie wieder das Projekt [Frontend sowie das Backend](https://gitlab.com/ch-tbz-it/Stud/m450/m450/-/blob/main/Unterlagen/projects/recipe-planner-fronend-and-backend.zip) von der [Pipeline Übung](https://gitlab.com/ch-tbz-it/Stud/m450/m450/-/blob/main/Unterlagen/ci-cd-pipeline/UEBUNGEN.md).

## Aufgabe 1

In der Frontend Applikation:
* Beide vom Team implementieren das gleiche Feature unabhängig

* Erstellen Sie jeweils einen Pull Request über die gleiche Feature Implementation
* Reviewen Sie sich gegenseitig und denke Sie an die Inputs von der [Theorie](https://gitlab.com/ch-tbz-it/Stud/m450/m450/-/tree/main/Unterlagen/code-reviews#qualit%C3%A4t-des-codes-ein-paar-beispiele)

* Tragen Sie ihre Erkenntnisse zusammen
